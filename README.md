# Mapa Interativo de Nova Crobuzon

Este projeto é um **mapa interativo da cidade fictícia de Nova Crobuzon**, inspirado na obra **"Estação Perdido"** de China Miéville. Ele permite adicionar, editar, excluir e buscar locais no mapa, bem como exportar ou copiar as coordenadas em JSON.

O mapa foi criado usando **Leaflet** com CRS simples para suportar imagens, **Bulma** para a interface e **SweetAlert2** para diálogos e notificações.

---

## 🌆 Funcionalidades

- Exibir o mapa da cidade de Nova Crobuzon a partir de uma imagem.  
- Adicionar locais clicando no mapa e definindo o nome.  
- Listar todos os locais marcados com coordenadas.  
- Editar ou excluir locais existentes.  
- Buscar locais pelo nome e destacá-los no mapa.  
- Salvar automaticamente no **LocalStorage** para persistência entre sessões.  
- Exportar os locais em arquivo JSON.  
- Copiar JSON para a área de transferência.  

---

## 💻 Tecnologias Utilizadas

- [Leaflet](https://leafletjs.com/) – Biblioteca de mapas interativos.  
- [Bulma](https://bulma.io/) – Framework CSS para layout e estilo.  
- [SweetAlert2](https://sweetalert2.github.io/) – Biblioteca para diálogos e alertas.  
- HTML, CSS e JavaScript puros.
